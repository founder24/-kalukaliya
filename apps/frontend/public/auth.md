# Auth.md

## Public content API

The published curriculum search API is read-only and does not require an account,
OAuth authorization, or an API token. Its OpenAPI description is available at
`https://syrabit.ai/.well-known/openapi.json`.

## Student and staff accounts

Student and staff sign-in is for interactive use of the Syrabit website. Those
sessions are not agent API credentials. Syrabit does not currently offer an
OAuth authorization server or agent-registration flow.
