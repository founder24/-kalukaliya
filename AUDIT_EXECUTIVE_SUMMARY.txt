🔴 CRITICAL ISSUES (Block Production)
───────────────────────────────────────────────────────────────────────────────

1. AUTHENTICATION BYPASS
   File: apps/backend/app/api/v1/auth.py:47
   Problem: get_current_user(token: str = Depends(lambda: None))
   Impact: All API endpoints unauthenticated, user impersonation trivial
   Fix Time: 30 minutes
   Status: 🔴 BLOCKING

2. MISSING DEPENDENCY INJECTION
   File: apps/backend/app/api/v1/chat.py:51
   Problem: async def chat(request: ChatRequest, user: User = None)
   Impact: User context never populated, rate limiting broken
   Fix Time: 30 minutes
   Status: 🔴 BLOCKING

3. ANONYMOUS USER QUOTA COLLISION
   File: apps/backend/app/api/v1/chat.py:36
   Problem: key = f"rate:{user_id}:{month}" (all anons share "rate:anonymous")
   Impact: One user can exhaust quota for ALL anonymous users (DoS)
   Fix Time: 1 hour
   Status: 🔴 BLOCKING

4. MISSING IMPORT
   File: apps/backend/app/api/v1/chat.py:42
   Problem: from datetime import datetime (missing timedelta)
   Impact: Potential runtime NameError
   Fix Time: 5 minutes
   Status: 🔴 BLOCKING
