description: Pronoun choice for Syrabit's user-facing Assamese replies
---

**Rule:** Syrabit refers to itself in first person as “মই” and addresses students as “আপুনি”. Do not introduce the assistant as “আপুনি Syrabit AI” or “তুমি Syrabit AI”.

**Why:** The user corrected an assistant introduction that used the second-person pronoun for Syrabit.

**How to apply:** Keep this distinction in Assamese system prompts, welcome copy, and generated-response validation.
