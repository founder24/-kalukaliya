Makers of Modern Assam (MDC-01013) has separate first-semester subject records for B.A., B.Com, and B.Sc. Preserve those records and their stream associations, but consolidate identical same-class copies into one library card that lists every available stream. Use the B.A. record as the display representative when available.

**Why:** The copies resolve to the same subject URL and represent one shared syllabus; deleting records would discard valid stream-specific catalog associations.

**How to apply:** Deduplicate only the library presentation by course slug and class. Keep saved-subject aliases functional, and do not remove the underlying D1 records unless the curriculum owner explicitly requests a data consolidation.
