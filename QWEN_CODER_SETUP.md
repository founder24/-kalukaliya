## 📖 Repository Overview

### Project: Syrabit
A full-stack AI-powered learning platform with:
- **Edge Layer**: Cloudflare Workers (Workers Scripts + Pages)
- **Backend**: Azure Container Apps (FastAPI)
- **Storage**: Cloudflare R2, D1, KV, Vectorize
- **Frontend**: React SPA (Vite)
- **Infrastructure**: IaC with HCL (Terraform), Python, TypeScript

### Key Components

```
artifacts/
├── syrabit/                           # Main analytics & chat app
│   ├── workers/embed-worker/          # Embed generation Worker (Pinecone-1024)
│   ├── workers/edge-proxy/            # Edge routing & AI fallback
│   └── src/                           # React SPA (Vite)
├── syrabit-backend/                   # FastAPI backend (Azure Container Apps)
│   └── scripts/monitoring/            # GCP Cloud Monitoring alerts

├── wire_cloudflare_secrets.sh         # 🔑 Secret provisioning automation
└── smoke.sh                           # Embed worker smoke tests

└── r2-lifecycle/                      # R2 bucket lifecycle rules (IaC)

└── embed-worker-staging-deploy.yml    # CI/CD pipeline (failing - see fixes)
```

## 🛠️ Step-by-Step Setup

### **Step 1: Clone Repository & Navigate**

```bash
git clone https://github.com/founder24/-kalukaliya.git
cd -kalukaliya
```

### **Step 2: Export Environment Variables**

```bash
# Add to your shell profile (~/.bashrc, ~/.zshrc, or .env file)
export CLOUDFLARE_API_TOKEN="<your-token>"
export CLOUDFLARE_ACCOUNT_ID="d66e40eac539fff1db270fddf384a5ec"

# Verify
echo "CLOUDFLARE_API_TOKEN set: ${#CLOUDFLARE_API_TOKEN}"
echo "CLOUDFLARE_ACCOUNT_ID: $CLOUDFLARE_ACCOUNT_ID"
```

### **Step 3: Install Root Dependencies**

```bash
# Install pnpm (if not global)
npm install -g pnpm@10.26.1

# Install all workspace dependencies
pnpm install

# Verify installation
pnpm --version
which pnpm
```

### **Step 4: Install Wrangler CLI**

```bash
# Install wrangler globally (required for Worker deployment)
npm install -g wrangler@4
wrangler --version  # Should be 4.x or higher

# Authenticate with Cloudflare
wrangler login
# Follow the browser prompt to authorize
```

### **Step 5: Wire Cloudflare Secrets (Primary Setup Script)**

This script generates and deploys all required secrets:

```bash
# Make the script executable
chmod +x scripts/wire_cloudflare_secrets.sh

# Run the secret wiring script
./scripts/wire_cloudflare_secrets.sh

# What it does:
# 1. Generates 4 cryptographically secure secrets (64 chars each):
#    - AI_FALLBACK_SECRET
#    - AI_FALLBACK_SECRET_PROD
#    - BACKEND_ORIGIN_SECRET
#    - D1_SYNC_SECRET
#
# 2. Detects Worker subdomain from wrangler.toml
#
# 3. Creates workers/edge-proxy/.dev.vars for local `wrangler dev`
#
# 4. Deploys secrets to:
#    - Cloudflare Workers (production)
#    - Cloudflare Workers (preview/staging)
#
# 5. Outputs environment variables for Google Cloud Run backend
#
# SAVE the output immediately — the secrets are printed once!
```

### **Step 6: Fix Dependency Lock File** ⚠️ (CRITICAL - Failing Workflow)

The embed worker has a **version mismatch** that breaks CI:

```bash
# Navigate to embed worker directory
cd artifacts/syrabit/workers/embed-worker

# Install dependencies (updates lock file to match package.json)
pnpm install --ignore-workspace

# Verify wrangler was updated to 4.92.0
pnpm list wrangler

# Return to repo root
cd ../../../..

# Update root lock file
pnpm install

# Commit the fix
git add pnpm-lock.yaml artifacts/syrabit/workers/embed-worker/pnpm-lock.yaml
git commit -m "fix: update wrangler dependency locks for 4.92.0"
git push origin main
```

### **Step 7: Add Missing GitHub Secrets** (Required for CI/CD)

Go to: **GitHub Repository → Settings → Secrets and variables → Actions**

Add these secrets:

| Secret Name | Value | Source |
|---|---|---|
| `CLOUDFLARE_API_TOKEN` | Your API token | Cloudflare Dashboard → API Tokens |
| `CLOUDFLARE_ACCOUNT_ID` | Account ID (32-char hex) | Cloudflare Dashboard → Account Overview |
| `EMBED_STAGING_SHARED_SECRET` | Generated by `wire_cloudflare_secrets.sh` | Output from setup script |

### **Step 8: Deploy Embed Worker (Staging)**

```bash
# Navigate to embed worker
cd artifacts/syrabit/workers/embed-worker

# Deploy to staging environment
pnpm run deploy:staging

# Expected output:
#   ✓ Uploaded embed-worker (X.XX sec)
#   ✓ Published to embed-staging.syrabit.ai
```

### **Step 9: Run Smoke Test (Verification)**

```bash
# Return to repo root
cd ../../../..

# Set the staging secret in environment
export EMBED_STAGING_SHARED_SECRET="<your-secret>"

# Run smoke test
cd artifacts/syrabit/workers/embed-worker
./scripts/smoke.sh staging

# Expected output:
#   ✓ /health → 200, dims=1024, version ends in -staging
#   ✓ /version → echoes health's dims + version
#   ✓ POST /embed → 401 without X-Embed-Secret
#   ✓ POST /embed → 1024-dim vectors with secret
#   === PASS (staging) ===
```

### **Step 10: Deploy Edge Proxy (Optional)**

```bash
# For local development only:
cd workers/edge-proxy
wrangler dev

# For production deployment:
# (Requires additional secrets — see CI workflow)
wrangler deploy
```

## 🐛 Current Issues & Fixes

### **Issue #1: Wrangler Version Mismatch** ❌ (BLOCKING)

**Symptoms**: CI workflow `embed-worker-staging-deploy` fails with:
```
specifiers in the lockfile don't match specifiers in package.json:
* wrangler (lockfile: ^3.78.0, manifest: ^4.92.0)
```

**Root Cause**: Lock file has old wrangler 3.78.0, but package.json requires 4.92.0

**Solution** (already documented in Step 6):
```bash
cd artifacts/syrabit/workers/embed-worker
pnpm install --ignore-workspace
git add pnpm-lock.yaml
git commit -m "fix: update wrangler to 4.92.0"
git push
```

### **Issue #2: Missing GitHub Secrets** ❌ (BLOCKING)

**Symptoms**: CI workflow fails with:
```
::error::CLOUDFLARE_API_TOKEN repo secret is not set.
::error::CLOUDFLARE_ACCOUNT_ID repo secret is not set.
```

**Solution**: Add secrets to GitHub (documented in Step 7)

### **Issue #3: Embed Worker Staging Secret Not Configured** ❌ (BLOCKING)

**Symptoms**: Smoke test fails with 401 on auth check

**Solution**: 
1. Generate secret: `openssl rand -hex 32`
2. Deploy to worker: `wrangler secret put EMBED_SHARED_SECRET --env staging`
3. Add to GitHub secrets: `EMBED_STAGING_SHARED_SECRET`

## 🔧 Troubleshooting

### **Problem: `pnpm: command not found`**

```bash
# Solution: Install pnpm globally
npm install -g pnpm@10.26.1
# Verify
which pnpm
```

### **Problem: `wrangler: command not found`**

```bash
# Solution: Install wrangler CLI
npm install -g wrangler@4
# Verify
which wrangler
wrangler --version
```

### **Problem: `pnpm install` fails with peer dependency warnings**

```bash
# Solution: Use --legacy-peer-deps flag
pnpm install --legacy-peer-deps
```

### **Problem: `wrangler login` fails or times out**

```bash
# Solution 1: Manually set API token
export CLOUDFLARE_API_TOKEN="<your-token>"

# Solution 2: Use interactive login
wrangler login --reauth

# Solution 3: Check firewall/proxy settings
curl -I https://api.cloudflare.com/
```

### **Problem: Embed worker deploy fails with `403 Unauthorized`**

```bash
# Solutions:
# 1. Verify token has correct permissions
#    Cloudflare Dashboard → API Tokens → Review token scope
#
# 2. Verify account ID is correct
#    Should match: d66e40eac539fff1db270fddf384a5ec
#
# 3. Verify token hasn't expired
#    Regenerate if >1 year old
#
# 4. Try explicit auth
export CLOUDFLARE_API_TOKEN="<new-token>"
wrangler deploy
```

### **Problem: Smoke test fails with `Connection refused`**

```bash
# Verify worker is deployed
curl -I https://syrabit-embed-worker-staging.axomxplain.workers.dev/health

# If 404: Worker not deployed
cd artifacts/syrabit/workers/embed-worker
pnpm run deploy:staging

# If timeout: Check Cloudflare dashboard for deploy status
# Settings → Overview → Recent Deploys
```

### **Problem: TypeScript compilation errors in scripts**

```bash
# Solution: Build type definitions
pnpm run typecheck

# If still failing:
rm -rf node_modules pnpm-lock.yaml
pnpm install
pnpm run typecheck
```
