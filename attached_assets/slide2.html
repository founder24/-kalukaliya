TECHNICAL DIFFERENTIATORS
01 · Dual-Language RAG Pipeline
Single retrieval pipeline serves both English and Assamese queries from the same indexed corpus. Language-conditioned prompting switches generation language without separate indices, cutting storage ~40%. Query embedding uses multilingual BGE-M3 (1024-dim) — identical vector space for both languages. Metadata filter applied at search time: lang ∈ {en, as}.
02 · Curriculum-Scoped Retrieval
Metadata filters applied at vector-search time — not post-hoc. Filter keys: board_id, class_id, subject_id, chapter_id. Ensures retrieved chunks are syllabus-relevant, reducing hallucination rate to <2% on in-scope topics. Filter cardinality spans 6-level hierarchy × 3 boards × 4 class groups × N subjects.
03 · Persistent Student Memory
MongoDB document per student accumulates topics_studied[], weak_areas[], doubt_history[]. Injected into every prompt as a structured prior-context block (max 800 tokens). Enables multi-session personalisation not possible in stateless LLM deployments. Memory updated via async write after each session using upsert.
04 · Human-in-the-Loop Content QC
Staff publish pipeline: raw_content → chunker → translator → embedder → QC review → live. No auto-published AI-generated curriculum content. Version-controlled with optimistic locking (version counter per chapter document). Dual-language translation validated before indexing. Rollback supported at any stage.
05 · Edge-First Architecture
Cloudflare Workers handle routing, JWT auth, CORS, rate-limiting, and embedding API calls at the edge — before origin is reached. P95 TTFB <400 ms for cached responses. LLM origin (Cloud Run) invoked only for generation and DB writes. Rate-limit enforced per user per window using distributed KV. No cold-start latency on auth or retrieval paths.
