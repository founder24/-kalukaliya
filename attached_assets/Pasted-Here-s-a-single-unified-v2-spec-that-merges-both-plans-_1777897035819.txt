## **Top‑line policy**

> **“Each major function uses 2 or 3 providers only where a meaningful Tier‑3 exists. Functions that are inherently single‑provider (e.g., Razorpay, AdSense, Trustpilot, Web Risk) are declared as such. English exam‑Q&A RAG is Cloudflare‑Workers‑AI‑first (via @cf/meta/llama-3.2-1b-instruct as primary RAG model), with Azure GPT‑4.1‑mini as fallback and Vertex Gemini 2.5 Flash as tertiary orchestration. Embeddings primary is Cohere direct API (no Bedrock); vector DB is Pinecone‑only with CF Vectorize as edge‑cache; Vertex Vector Search and Discovery Engine are retired. Moderation uses Llama Guard (primary) + Azure AI Content Safety (secondary); Gemini RAI is opt‑in only for high‑stakes exam‑model‑paper flows. Indic‑chat / Indic‑translation is Sarvam‑first; Assamese‑chat is Sarvam‑M‑first; Assamese‑content‑translation is Cloudflare Workers AI indictrans2‑en‑indic‑1b primary. App infra is distributed equally between Cloudflare (edge / RAG‑primary), Azure (backend / auth), and AWS (serverless / storage / eventing), all within free‑tier‑friendly workloads. All SLOs, error‑budgets, and credit‑burn thresholds are explicit, testable, and owned.”**

## **3. Technical constraints / model‑bindings (workers‑AI‑level)**

- `@cf/meta/llama-3.2-1b-instruct`:
  - **Latency**: ~876 ms, **~87 tokens/sec** → **fastest‑small‑LLM on Workers‑AI**. [fredhii](https://www.fredhii.com/posts/cloudflare-workers-ai-production-guide)
  - **Pricing**: cheaper per‑token than `gpt‑oss‑20b` / `gpt‑oss‑120b`, hence **ideal for RAG‑burn‑volume**. [artificialanalysis](https://artificialanalysis.ai/providers/cloudflare)
- `@cf/openai/gpt‑oss‑120b`:
  - **Latency**: ~858 ms, **120B‑size**, **$0.35 / 1M input‑tokens**, **$0.75 / 1M output‑tokens** → **high‑quality, high‑cost**. [crackedaiengineering](https://www.crackedaiengineering.com/ai-models/cloudflare-workers-ai-gpt-oss-120b)
- `@cf/ai4bharat/indictrans2‑en‑indic‑1b`:
  - **Indic‑1b‑translation** model, supports all 22 scheduled Indic languages; optimized for English‑→‑Indic‑direction. [developers.cloudflare](https://developers.cloudflare.com/workers-ai/models/indictrans2-en-indic-1B/)

These are **now locked‑in as your default‑model‑bindings** for the v2 plan.
