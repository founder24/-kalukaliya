You are deploying and auditing a fullstack monorepo called "Syrabit" (syrabit-monorepo v3.0.0).

## Project Structure
- **Backend**: FastAPI (Python 3.11+) at `apps/backend/` — runs on port 4000 (uvicorn)
- **Frontend**: React 18 + Vite 7 + TailwindCSS at `apps/frontend/` — runs on port 25144
- **Edge**: Cloudflare Worker at `apps/edge/` (NOT used for chat/AI — only edge shield/routing)
- **Infra**: MongoDB 7, Redis 7 (with Upstash-compatible REST proxy via serverless-redis-http)
- **Package Manager**: pnpm 10.26+ (workspace monorepo), Node >= 22
- **Docker Compose**: defines mongo, redis, redis-rest, and backend services

## AI/Chat Integration Rules
- English language slot/chat: Google Vertex AI
- Assamese language slot/chat: Sarvam AI
- Do NOT use Cloudflare Worker AI for chat functionality

## Step 1: Environment Setup
1. Install Python 3.11+ dependencies: `cd apps/backend && pip install -r requirements.txt`
2. Install Node dependencies: `pnpm install` (from root)
3. Set up MongoDB (use Replit's built-in or a free Atlas cluster)
4. Set up Redis (use Replit's KeyDB or Upstash free tier)
5. Create `.env` at root with:
   - MONGODB_URI=<connection string>
   - UPSTASH_REDIS_REST_URL=<redis rest url>
   - UPSTASH_REDIS_REST_TOKEN=<redis rest token>
   - APP_ENV=development
   - DEBUG=True
   - VERTEX_AI credentials (for English chat)
   - SARVAM_AI_API_KEY (for Assamese chat)

## Step 2: Start Services
1. Backend: `cd apps/backend && python -m uvicorn app.main:app --reload --host 0.0.0.0 --port 4000`
2. Frontend: `cd apps/frontend && pnpm dev` (serves on port 25144, proxied to 0.0.0.0)
3. Verify backend health: `curl http://localhost:4000/health`
4. Verify frontend loads: open the Replit webview on port 25144
