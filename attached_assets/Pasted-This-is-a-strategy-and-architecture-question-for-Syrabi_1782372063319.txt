Cloudflare Workers AI for Embeddings — Can it work?
Yes — use @cf/baai/bge-m3

Model	Dims	Languages	Assamese?

BGE-M3 specifically supports Assamese (ISO code as) — it's trained on the mC4 multilingual corpus which includes Assamese text.

How to call it from your Python backend — you already have CF_ACCOUNT_ID and CF_WORKER_AI_TOKEN in config:

# apps/backend/app/services/ai/cf_embedder.py
import httpx
from app.config import settings
CF_EMBED_URL = (
    f"https://api.cloudflare.com/client/v4/accounts/"
    f"{settings.CF_ACCOUNT_ID}/ai/run/@cf/baai/bge-m3"
)
async def embed_texts(texts: list[str]) -> list[list[float]]:
    """Embed a batch of texts using CF Workers AI bge-m3 (1024 dims, multilingual)."""
    async with httpx.AsyncClient(timeout=30) as client:
        resp = await client.post(
            CF_EMBED_URL,
            headers={"Authorization": f"Bearer {settings.CF_WORKER_AI_TOKEN}"},
            json={"text": texts},
        )
        resp.raise_for_status()
        data = resp.json()
        return data["result"]["data"]  # list of 1024-dim vectors

Trade-offs vs Vertex AI Multilingual Embedding
CF bge-m3	Vertex text-multilingual-embedding-002
Dims	1024	768
Assamese quality	Good (mC4 corpus)	Better (Google's Indic data)
Cost	~$0.02/M tokens	~$0.025/M tokens
Latency	~100-200ms	~150-300ms
Already on infra	✅ CF account exists	✅ GCP SA exists
Batch size limit	100 texts	250 texts
Honest verdict: For Assamese educational content (short definitions, questions, notes), bge-m3 will work well and is cheaper. If you find retrieval quality lacking for Assamese-heavy queries specifically, you can always switch to Vertex later — the vector index just needs a reindex.
