# Full Stack Provider Delegation Matrix

Distribute workloads equally (25%) across Cloudflare, AWS, Azure, GCP backbones for infra/hosting/compute, proxying non-replaceable small/specialized providers (Supabase/MongoDB/Pinecone/Upstash/Sarvam/Deepgram etc.) via credit-weighted dispatchers—remove Railway/Vercel. Leverages all startup credits (~$900K runway) without replacement; e.g., GCP keeps Vertex/GA4 (irreplaceable Indic), AWS SQS/SES active. [gartsolutions](https://gartsolutions.com/comparing-aws-gcp-and-azure-startup-programs/)

## Core Principles
- **Backbones (25% equal)**: Handle hosting, jobs, storage, obs—via config.py dispatcher.
- **Specialized (100% pinned)**: Supabase auth, Pinecone vectors, Upstash cache, GCP Vertex/GA4, AWS SES—non-replaceable.
- **AI Proxy**: CF AI Gateway routes LLM chains credit-weightedly.
