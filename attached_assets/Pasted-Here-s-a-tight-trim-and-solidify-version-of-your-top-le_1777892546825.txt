  4. **Post‑processing / filtering**:

  5. **Response** → back to **Cloudflare AI Gateway** → client.

- **Delegation**:

## **2. Library Page Load Latency Minimization**

**Goal**: Minimize **page‑load latency** for **library‑page** (assam‑board‑question‑bank‑style pages), including metadata, exam‑info, question‑preview‑text.

- **Architecture**:

| Layer                    | Provider / Tool                                      | Role / Optimization                                                            |
|---------------------------|-------------------------------------------------------|---------------------------------------------------------------------------------|
| **Edge / CDN**           | `Cloudflare Pages` + `Cloudflare Cache Reserve`      | Cache full‑page / SSR‑output; edge‑deliver from nearest PoP.                  |
| **Edge‑logic**           | `Cloudflare Workers`                                  | Inject exam‑block / exam‑meta‑scripts at edge; no full‑RAG on‑first‑load.     |
| **Metadata / CMS**       | `MongoDB Atlas` (via `Supabase`‑sync / GraphQL)      | Pre‑render question‑metadata into HTML; avoid runtime‑fetch‑heavy‑render.     |
| **Static assets**        | `Cloudflare R2`                                       | Serve PDF‑thumbnails, images, audio, etc. from edge.                           |
| **Client‑side hydration**| `React / Vite` + `Cloudflare Pages`                   | Hydrate content only if needed; lazy‑load heavy‑chunks (e.g., exam‑Pdf‑viewer). |

- **Latency‑specific tactics**:
  - **Pre‑bake exam‑meta**:  
    - Cache exam‑metadata (board, class, subject, chapter) as **static JSON chunks** at edge.  
  - **Edge‑precompute**:  
    - Use `Cloudflare Workers` to **pre‑embed / pre‑rank** top‑100 Qs per‑exam (for “fast‑preview” sidebar).  
  - **Pinecone‑edge‑cache**:  
    - Use `CF Vectorize` to cache **top‑100 embeddings** per‑exam.  
  - **Lazy‑RAG**:  
    - Full RAG‑parsing (via `Vertex Gemini`) is done **on‑request** for “deep‑exam‑analysis” tab, not on‑page‑load.  
  - **CDN‑busting policy**:  
    - Use short‑TTL for **question‑change‑detected** flags, but long‑TTL for static‑exam‑layout.
