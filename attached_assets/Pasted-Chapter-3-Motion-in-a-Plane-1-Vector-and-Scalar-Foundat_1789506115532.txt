Classification Criteria and Definitive Properties
 * Scalar Quantities: Completely described by a numerical magnitude and algebraic sign. They obey the rules of ordinary algebra. Examples include volume, mass, speed, density, number of moles, angular frequency, temperature, pressure, time, work, power, gravitational potential, coefficient of friction, and electric charge.
   * Electric Current: Possesses magnitude and a directional sense along a conductor, yet is classified as a scalar because currents add algebraically at circuit nodes (I_{\text{net}} = I_1 + I_2) according to charge conservation, rather than by vector addition laws.
   * Hydrostatic Pressure: Classed as a scalar because the compressive contact force exerted by a static fluid acts perpendicularly against any bounding surface regardless of the surface's spatial orientation.
   * Coordinate Invariance: A scalar quantity has the same value for observers using different orientations of reference axes. A scalar is not required to be conserved in a physical process (for instance, kinetic energy in an inelastic collision is not conserved), nor is it forbidden from taking negative values (such as negative work, electric potential, or temperature in degrees Celsius).
 * Vector Quantities: Possess both a magnitude and a spatial direction, and fundamentally satisfy the triangle or parallelogram law of addition. Examples include displacement, velocity, acceleration, force, impulse, linear momentum, angular momentum, electric field, and angular velocity.
   * Magnitude Character: The magnitude (or absolute value) of a vector is intrinsically a positive scalar quantity or zero (|\vec{A}| = A \ge 0).

 * Adding Any Two Scalars: Valid if and only if both scalars represent physical quantities sharing identical physical dimensions and units (e.g., adding two masses is valid; adding mass to temperature is physically undefined).
 * Adding a Scalar to a Vector: Fundamentally meaningless under all circumstances, even if their dimensional formulas coincide. A pure directional entity cannot be combined with a non-directional scalar.
 * Multiplying a Vector by a Real Scalar (\lambda): Always meaningful. The operation yields a new vector \vec{B} = \lambda \vec{A} whose magnitude is |\lambda| |\vec{A}|. If \lambda > 0, the spatial direction is preserved; if \lambda < 0, the direction is inverted by 180^\circ. The scalar multiplier may carry physical dimensions (e.g., multiplying an acceleration vector \vec{a} by scalar mass m produces the dynamic force vector \vec{F} = m\vec{a}).
 * Adding Any Two Vectors: Meaningful if and only if the vectors represent the same physical quantity with identical units (e.g., adding two displacement vectors or two force vectors). Velocity vectors cannot be added to force vectors.
 * Adding a Component to a Vector: Meaningful only if the component is scaled by its directional unit vector to form an actual component vector (\vec{A} + A_x \hat{i}). Adding a scalar component magnitude A_x directly to the vector \vec{A} is invalid.
